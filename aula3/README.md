# Aula 3 — Análise Assintótica e Algoritmos Iterativos

Projeto baseado na estrutura da `aula1` para resolver a lista de exercícios da Aula 03.

## Como executar

```bash
cd "aula3/estrutudaDados"
javac -d out src/*.java
java -cp out Main
```

## Exercícios implementados

1. Busca sequencial e crescimento linear
2. Comparação de classes assintóticas
3. Melhor caso, caso médio e pior caso
4. Escolha entre soluções O(n) e O(n²)
5. Análise do Selection Sort
6. Selection Sort em números reais
7. Matriz de decisão para autocomplete
8. Fibonacci: constante, linear e quadrático
